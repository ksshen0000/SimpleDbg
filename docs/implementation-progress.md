## 测试组

- 核心集成：46 项，静态/动态/PIE/静态 PIE、ELF 版本、安全边界、进程/信号等。
- 工作流：19 项，步过/返回/递归及去符号回溯、省略帧指针拒绝、参数与内存修改、监视点、syscall、源码行、快照。
- 故障注入：6 项，通过仅测试链接器 wrap 注入真实 ptrace 错误：
  - 第二个机器字写入失败，验证第一个机器字回滚；
  - 快照中途内存写失败，验证当前数据及寄存器恢复；
  - XSAVE 恢复失败，验证已经恢复的内存再次回滚；
  - 写入或快照的回滚也失败，验证目标终止且不会继续部分状态。

另覆盖 GET_SYSCALL_INFO 失败：关闭捕获但不转交合成 SIGTRAP，目标仍可继续。
生产二进制没有故障注入环境变量处理或测试开关。

## 性能与安全处理

每次解析仍刷新进程映射，以发现 dlopen/dlclose。ELF 符号采用最多 64 项共享缓存，
按设备、inode、大小、mtime/ctime 校验，不重复深拷贝整张符号表。
已测试同一路径的库替换并重新加载，以及库内名称恰好全部是十六进制字符的函数。
快照大块读取优先使用 process_vm_readv，不可用时回退到 ptrace；写入保留逐字错误处理。

恢复严格拒绝在待投递信号、syscall 捕获停止或 Ctrl-C 暂停状态下备份内核在途状态。
代码断点、寄存器/内存修改、硬件监视点均在停止状态操作。

## 后续工作（未标记完成）

1. **独立目标 PTY**：与调试器命令通道分离，管理目标前台进程组与作业控制；保持 EOF 默认模式。
2. **DWARF 变量/表达式后端**：引入成熟 DWARF/unwind 库，处理作用域、位置列表、优化变量与内联帧。
3. **attach 后端**：区分“拥有并启动的进程”和“外部附加进程”，后者默认 detach，不能沿用退出即 kill。
   还需全线程停止、软件/硬件断点恢复、fork/exec 期间 detach 的失败语义和权限测试。
4. **core 后端**：独立只读地址空间，解析 ELF PT_NOTE/NT_PRSTATUS/NT_FPREGSET/NT_X86_XSTATE/NT_FILE，
   验证偏移/范围后复用寄存器、内存、符号和栈显示；禁止运行/写命令。
5. **remote 后端**：先定义地址空间、寄存器、停止原因接口，再实现 GDB RSP 包校验、转义、重传、
   连接超时与断点同步；默认只绑定本地地址，不能把本地 ptrace 生命周期直接暴露为网络控制。
6. **完整多线程**：所有线程停止后共享断点，维护每个 TID 的停止原因和临时单步状态，再替换当前安全拒绝策略。

这些功能没有通过命令占位或“成功”输出冒充实现。P3 的正式范围应在已有 P2 的后续清单上定义。
